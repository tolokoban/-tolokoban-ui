    • Optionalchildren?: React.ReactNode

      Content of the button. Most often a text, but can be anything.

    • Optionalcolor?: OpaqueColorName

      Main color of the button. It will be the background, unless we use variant="text" or variant="outline".

    • Optionalenabled?: boolean

      Default to true.

      If set to false, the button cannot get the focus and cannot be clicked.

    • Optionalicon?: React.FC<GenericIconProps>

      Icon to display to the left.

    • OptionaliconRight?: React.FC<GenericIconProps>

      Icon to display to the right.

    • Optionallabel?: React.ReactNode

      This property is here for backward compatibility. It is an alias for children. But if both props are defined, children takes precedence.

    • OptionalonClick?: string | ((this: void) => void)

      Click handler.

      If you set a string, the button will be turned into a link to an URL. But the style will remain the same.

    • Optionaltarget?: string

      If the button is a link (onClick is a string), then target is used to open in a new tab.

    • OptionaltextAlign?: "center" | "left" | "right"

      Horizontal alignment of the content (children or label).

      Default to "center".

    • Optionalthickness?: string | number

      Thickness of the button's border.

      For variant="outlined", the border has the main color. For the other variants, its color is a mix between the main color and the text color.

      The border is drawn inside the button: its height does not change.

      Default to 0.125 for variant="outlined", and to "1px" otherwise.

    • Optionalvariant?: "elevated" | "filled" | "outlined" | "text"

      The look of a button depends on its variant:

      • filled (default): button ith background.
      • elevated: with a shadow below.
      • outline: no background but a surrounding border.
      • text: text only, no background, no border.

      Default to "filled".

    • Optionalwaiting?: boolean

      If true, an icon will rotate and the button will be disabled.
